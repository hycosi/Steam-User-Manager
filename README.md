# Steam User Manager

Расширение Manifest V3 для Chrome и Edge 120+: несколько аккаунтов Steam в одном браузере, отдельные сессии во вкладках, коды Steam Guard и мобильные подтверждения. Работает только на сайтах Steam, Node.js для использования не нужен.

## Возможности

- **Список аккаунтов** с аватаром, уровнем и анимированным фоном профиля. Поиск по имени и логину (клавиша `/`).
- **Быстрые кнопки** слева от аватара: сделать аккаунт основным в браузере, открыть в новой вкладке, войти заново.
- **Отдельные сессии.** «Открыть» создаёт вкладку со своими cookies и `localStorage` выбранного аккаунта; остальные аккаунты не затрагиваются.
- **Steam Guard:** код с таймером и копированием по клику. Нужен `shared_secret` (можно импортировать из maFile).
- **Подтверждения** обменов и торговой площадки (нужны `identity_secret` и `device_id`).
- **Ссылки аккаунта:** до 18 закладок на аккаунт, очистка данных сайта.
- **Резервная копия:** экспорт и импорт всех аккаунтов одним JSON-файлом с предварительным просмотром.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) или клонируйте его и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`).
3. Включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку с `manifest.json`.
4. Закрепите расширение на панели браузера.

Обновление: замените файлы в той же папке и нажмите кнопку обновления на карточке расширения. Данные сохранятся. При смене папки или браузера сначала экспортируйте JSON-копию. Установка из Chrome Web Store имеет отдельный идентификатор и отдельное хранилище.

## Использование

| Действие | Как |
| --- | --- |
| Добавить аккаунт | «Добавить» → логин и пароль. Код Steam Guard можно ввести или подтвердить вход в приложении Steam. maFile импортируется кнопкой «Импорт maFile». |
| Открыть отдельную сессию | «Открыть» или иконка со стрелкой на строке аккаунта. |
| Сделать основным | Иконка человечка: cookies аккаунта ставятся в обычную сессию, открытые вкладки Steam перезагружаются. Клиент Steam на компьютере не переключается. |
| Войти заново | Иконка обновления или пункт меню «⋯». |
| Steam Guard, ссылки, управление | Нажмите на имя или аватар аккаунта. |

### Резервные копии

Экспорт: «Резервная копия» → «Скачать .json». Файл содержит логины, **пароли, секреты Steam Guard**, cookies и сохранённый `localStorage` в открытом виде. Храните его так же аккуратно, как пароли. Файл создаётся на устройстве и никуда не отправляется.

Импорт: «Выбрать .json», проверить список (добавить / обновить / пропустить), «Импортировать». По умолчанию существующие аккаунты пропускаются; обновление включается отдельной галочкой. Файл проверяется целиком до применения; ошибка в любой записи отменяет весь импорт (лимит 20 МБ и 1 000 аккаунтов).

## Безопасность и ограничения

- Пароли и секреты хранятся локально, без отдельного шифрованного хранилища.
- Content scripts получают данные только своей вкладки, без паролей, секретов и HttpOnly cookies. Полный экспорт доступен только страницам самого расширения.
- Сетевые разрешения ограничены Steam и его поддоменами. Ссылки на сторонние сайты открываются с обычной сессией этих сайтов.
- Разделяются cookies и `document.cookie`, `localStorage`, `sessionStorage` вкладок. IndexedDB, Cache Storage и service workers сайтов не разделяются, это не отдельные профили браузера.
- Вкладки, открытые самим сайтом через `window.open`, могут сделать первый запрос до установки правил. Для надёжной изоляции открывайте аккаунты через расширение.
- После полного перезапуска браузера отдельные вкладки нужно открывать заново.
